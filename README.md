# EAInesy

Neuro-symbolic research demonstrator.

## Development

See `package.json` for scripts and `docs/V2-GESPREKSREGIE.md` for conversation control design.

Provide runtime credentials in a local `.env` file. **Never commit credentials or user data.**

## Status

Research prototype. Formal verification is restricted to modeled symbolic rules. Not a clinically validated tool, crisis service or evidence of reliability in live human interactions.

## Integration

Future API/MCP adapters must preserve central risk detection, policy decisions and audit semantics. Test runs must remain isolated from production review and adaptive memory.
